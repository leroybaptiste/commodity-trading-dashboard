# Commodity Trading & Hedging Dashboard

This project aims to build a commodity trading dashboard using Python, Streamlit, Excel and VBA.

## Objective

The goal is to create a practical tool for commodity market monitoring, futures curve analysis, hedging simulation and risk management.

## Current version

Initial Streamlit application setup.

## Planned modules

1. Market Overview
2. Futures Curve Analysis
3. Hedging Simulator
4. Risk Management

## Technologies

- Python
- Streamlit
- pandas
- numpy
- plotly
- Excel
- VBA
